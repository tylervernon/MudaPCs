# MudaPcs

MudaPcs is a PC e-commerce website project designed to showcase and sell custom-built gaming PCs.

## Features

- Gaming PC product listings
- Individual product pages
- PC specifications and performance information
- Product availability and sold-out states
- Order tracking interface
- Website terms and privacy pages
- Responsive web design

## Tech Stack

- HTML
- CSS
- JavaScript
- Replit

## Status

**In active development.**

MudaPcs is an ongoing project, with additional features, improvements, and website functionality still being developed.

## Purpose

I built MudaPcs to combine my interests in computer hardware and software development while creating a practical e-commerce website for custom gaming PCs.
